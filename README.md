## Description : 
Projet réalisé dans le cadre de l'UE MIDL 1.
L'objectif de cette première partie est la mise en place de la représentation des formules et la recherche de preuves simplles avec le calcul des Tableaux.

## Structure du projet :
- 'datastructs.py' : Fichier de définitions des structures de données
- 'test_formules.py' : Fichier contenant les fonctions sur les formules, 4.1
- 'main.py' : Fichier de test et d'exécution des fonctions

## Utilisation :
Pour exécuter les tests il suffit d'exécuter le fichier 'main.py'
